# Poppler Crunchers

This page is linked from index.md to show multi-page bundle ingest.

## Available tasks

- pdf2text: extract structural text from PDF
- pdf2images: render each PDF page to image
- pdfimages: extract embedded images in original resolution
- pdfinfo: document information (title, author, dates, page size)
